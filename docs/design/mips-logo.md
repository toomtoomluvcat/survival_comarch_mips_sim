## Generation prompt

Use case: logo-brand. Asset type: a single square pixel-art logo for a MIPS CPU simulator with a Classic Mac OS desktop theme. Primary request: design a very cute smiling CPU microchip mascot in authentic 8-bit pixel art. Subject: one front-facing square microchip, short pins on all four sides, two big dark square eyes, a tiny friendly smile, subtle rosy cheek pixels. Style: a simple low-resolution 24x24 pixel-grid sprite enlarged using crisp nearest-neighbor blocks, consistent pixel size, clean dark outline, no antialiasing, no gradients or soft shadows. Palette: restrained pastel teal and cream with dark charcoal outlines to fit a muted teal and gray retro desktop. Composition: centered icon filling about 88% of a square canvas; strong readable silhouette at 20px, minimal detail, balanced padding. Background: genuine transparent alpha, not a checkerboard illustration. Text: none. Output: one standalone PNG logo, no mockup, no lettering, no watermark, no extra characters or decorations.
